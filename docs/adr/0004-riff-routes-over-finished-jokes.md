# ADR 0004: Teach riff routes instead of finished jokes

## Status

Accepted

## Context

The simulator needs to help apprentice comedians learn how to think faster. If the post-round analysis gives complete jokes as the main output, the product can feel like it is replacing the performer instead of training them.

## Decision

Post-round analysis will present riff routes: opportunity, why it works, several angle directions, and at most one clearly labeled example line per opportunity.

## Consequences

The apprentice comedian keeps authorship. The product teaches structure and perception rather than encouraging dependency on AI-written punchlines.

The UI should emphasize routes, connections, and reasoning before example lines.
